# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** Tipografi rapi, kedalaman seimbang (garis 1px dulu, bayangan lembut seperlunya), tabel data elegan, kejelasan tinggi. Tiga ruang kerja memakai satu sistem yang sama dengan kerapatan berbeda: Command Center NFR desktop-first dan padat; Portal Tenant responsif dan tenang; Portal Dealer mobile-first dengan teks besar dan tindakan jelas. Warna merek Pertamina dipakai hemat (60-30-10): kanvas netral, biru untuk tindakan utama, merah hanya untuk status kritis. Token warna ada di `src/app/globals.css`.

## Banned anti-aesthetics

- Glassmorphism / `backdrop-filter` tanpa batas berkontras tinggi
- Lencana pil pastel mengambang untuk metadata biasa
- Gradien dekoratif dan garis neon menyala
- Gradien pelangi di tombol utama
- Ilustrasi kartun di tampilan kosong (orang melambai, tos)
- Scrollbar bersarang dan ikon berlebihan di dalam kolom isian

## Accessibility target

- **Level:** WCAG 2.1 AA (master prompt meminta orientasi WCAG 2.2 AA; kriteria 2.2 yang relevan ikut dipenuhi: target sentuh, fokus tidak tertutup)
- **Contrast:** > 4,5:1 untuk teks biasa, 3:1 untuk teks besar dan garis komponen. Status penting tidak pernah hanya dibedakan dengan warna: selalu ada teks atau ikon.
- **Touch / focus:** Target sentuh minimal 44×44 px; cincin fokus terlihat (`:focus-visible` 3px biru, sudah ada di globals.css).

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Bahasa Indonesia yang jelas, membantu, dan memakai istilah bisnis sehari-hari, tanpa jargon teknis (mis. "Melengkapi jenis usaha yang sudah ada", bukan "Pelengkap bauran"). Tombol diawali kata kerja. Pesan galat tidak menyalahkan pengguna dan selalu menyebut langkah berikutnya. Nilai perkiraan, nilai kontrak, dan nilai terealisasi selalu diberi label berbeda. Skor kecocokan tidak pernah disebut sebagai peluang berhasil. Kartu penawaran juga tersedia dalam bahasa Inggris.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react` (belum terpasang saat profil ini dibuat; pasang saat pertama kali dibutuhkan)
- **Notes:** Satu pustaka untuk seluruh antarmuka. SVG tulis tangan yang sudah ada (panah galeri, logo) boleh tetap; ikon baru memakai Lucide. Tidak memakai emoji sebagai ikon.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
